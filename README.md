# 🔎 GitHub Profile Finder

A simple **GitHub Profile Finder** built using **HTML, CSS, and JavaScript**. It allows users to search for a GitHub username and view profile information using the GitHub REST API.

🌐 [**Live Demo**](https://sunny1901kumar-sys.github.io/GitHub-profile-finder/)

## 📸 Screenshot
![GitHub Profile Finder Screenshot](Screenshot.png)

## ✨ Features

- 🔍 Search GitHub users by username
- 👤 Displays profile picture, name, and username
- 📝 Displays the user's bio
- 👥 Shows followers and following counts
- 📦 Displays the number of public repositories
- 🔗 Direct link to the GitHub profile
- 📚 Quick access to the user's repositories
- ⏳ Shows a loading message while fetching data
- 🚫 Prevents searching with an empty input
- ❌ Shows an error when the user is not found
- ⚠️ Handles API and network errors
- 🧹 Removes extra spaces from the username input
- 🔄 Updates profile information dynamically
- 📱 Responsive design for mobile screens

## 🛠️ Technologies Used

- **HTML** – Structure
- **CSS** – Styling and responsive layout
- **JavaScript** – Profile search and user interactions
- **Fetch API** – Fetching data from the API
- **GitHub REST API** – Retrieving GitHub user information

## 🚀 How to Run

1. Clone the repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Enter a GitHub username and click **Search**.

## 🔄 How It Works

```text
GitHub Username
       ↓
GitHub REST API
       ↓
Fetch User Data
       ↓
Convert Response to JSON
       ↓
Display Profile Information
       ↓
Show Profile and Repository Links
```
